# Cross-project Patterns

두 프로젝트 이상에서 재사용할 수 있거나 다음 프로젝트에도 적용할 가치가 높은 지식을 보존한다.

- `architecture/`: 구조와 경계
- `debugging/`: 진단 전략
- `deployment/`: 배포·운영
- `environment/`: OS, 경로, 포트, 도구
- `ai-reliability/`: AI 검증, 증거, 작업 안전성

단일 프로젝트에서만 의미가 있는 내용은 `20-projects/`에 둔다.
