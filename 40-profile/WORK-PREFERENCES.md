# 공통 작업 선호

## 응답과 협업

- 기본 응답 언어는 한국어로 한다.
- 먼저 결과와 현재 상태를 말하고 필요한 설명을 뒤에 둔다.
- 사용자가 기술 세부사항을 모를 수 있으므로 위험한 작업은 효과를 평이하게 설명한다.
- 불확실한 내용은 추정으로 표시한다.

## 코딩 작업

- 작업 전에 기존 규칙, 현재 변경사항, 실제 코드 상태를 읽는다.
- 다른 AI나 사용자가 만든 미커밋 변경을 덮어쓰지 않는다.
- 완료를 주장하기 전에 관련 테스트와 실제 동작을 검증한다.
- 테스트하지 못한 항목은 검증 완료로 표현하지 않는다.
- 코드와 문서가 충돌하면 코드·Git·실행 결과를 우선하고 문서를 정정한다.

## 컨텍스트 기록

- 모든 대화를 저장하지 않는다.
- 현재 인계는 프로젝트 `NOW.md`에 짧게 유지한다.
- 검증된 중요 사건만 Vault에 승격한다.
- 재사용 가능한 교훈은 프로젝트 이름을 제거해 `30-patterns/`에 일반화한다.
- AI별 폴더를 영구 지식 저장소로 사용하지 않는다.
- 세션 시작·재개 시 기준 파일을 다시 읽고, 대화 기억만으로 현재 상태를 추정하지 않는다.

## 안전

- 비밀키, 토큰, 쿠키를 문서나 Git에 기록하지 않는다.
- 외부 배포, 결제, 공개 게시, Push 등은 권한 정책을 따른다.
- 삭제·덮어쓰기 전 정확한 대상을 확인하고 가능한 경우 백업한다.

이 문서가 공통 작업 선호의 기준이다. 실제 AI 전역 설정은 [[POLICY-DISTRIBUTION]]에 따라 배포되는 복사본이다.
