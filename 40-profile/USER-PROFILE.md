# 사용자 프로필

## 확인된 사실

- 주 사용 언어: 한국어
- 운영체제: Windows
- 여러 AI를 구독·토큰·사용량 상황에 따라 전환해 사용한다.
- 주력 도구: Claude Code
- 자주 사용하는 도구: Codex, Cursor, ChatGPT, Gemini
- 프로젝트 수가 많으며 AI를 바꿔도 작업이 이어지는 구조를 원한다.
- Obsidian을 AI 간 공유 지식 공간으로 사용한다.
- 단순한 AI 자기보고보다 실제 실행·검증 증거를 중요하게 여긴다.

## 기록하지 않을 것

- 인증정보와 개인정보
- 프로젝트별 상세 상태
- 일시적인 감정이나 한 세션의 선호
- 확인되지 않은 AI의 추론

프로젝트별 내용은 [[PROJECT-INDEX]]와 각 프로젝트 저장소를 사용한다.

이 문서가 사용자 프로필의 기준이며 AI 내장 메모리나 전역 설정의 복사본보다 우선한다.
