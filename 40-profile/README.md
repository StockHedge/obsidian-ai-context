# Profile

프로젝트와 무관하게 오래 유지되는 사용자 성향과 운영 정책을 보존한다.

이 디렉터리가 사용자 성향과 공통 운영 정책의 기준이다. AI 내장 메모리에 전부 복사하지 않으며, 각 AI 전역 설정에는 필요한 짧은 요약과 이 문서의 위치만 배포한다.
