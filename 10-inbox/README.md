# Inbox

AI가 아직 분류·검증하지 않은 초안을 임시로 두는 곳이다.

- AI별 하위 폴더는 작성 주체를 구분하기 위한 수신함일 뿐 지식 사일로가 아니다.
- 기준 정보로 인용하지 않는다.
- 7일 안에 프로젝트 사건·마일스톤·패턴으로 승격할지 검토한다.
- 30일 이상 가치가 확인되지 않으면 `90-archive/`로 이동한다.
- 현재 작업 인계는 여기에 쓰지 않고 프로젝트 저장소의 `docs/ai/NOW.md`에 쓴다.
- 매주 첫 작업, 기한 도래, 5건 누적, 단계 종료 시 [[INBOX-REVIEW]]에 따라 검토한다.
- AI는 처리 후보를 제안하고 최종 승격·보관·삭제는 사용자가 결정한다.
