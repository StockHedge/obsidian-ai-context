# Inbox 검토 규칙

## 검토 트리거

다음 중 하나가 발생하면 Inbox 검토를 시작한다.

- 매주 첫 AI 작업 세션
- `review_by`가 오늘이거나 지난 문서가 1개 이상일 때
- 미분류 문서가 총 5개 이상 쌓였을 때
- 프로젝트 단계 종료 또는 큰 인계 직전

AI는 작업 시작 시 해당 조건을 확인하고 사용자에게 검토 필요 항목을 알린다. 자동 승격·삭제는 하지 않는다.

## 담당

- 최종 승격·보관·삭제 결정: 사용자
- 분류, 중복 확인, 승격 후보 제안: 작업 중인 AI
- 현재 작업 인계 갱신: 해당 프로젝트를 마무리하는 AI

## 처리 선택

1. 프로젝트 사건·마일스톤·회고로 승격
2. 공통 패턴으로 일반화
3. 프로젝트 저장소의 `NOW.md` 또는 문서로 이동
4. 근거 부족이면 Inbox에 유지하고 새 `review_by` 지정
5. 30일 이상 가치가 확인되지 않으면 `90-archive/`로 보관

삭제는 중복이 명확하고 복구 가능한 이력이 있을 때만 한다.

## 검토 완료 조건

- 각 문서에 처리 결과가 정해졌다.
- 승격된 문서는 원문 근거와 검증 상태를 보존한다.
- 프로젝트 현재 상태가 Inbox에만 남지 않는다.
- 변경 결과를 로컬 Git 커밋으로 남긴다.
