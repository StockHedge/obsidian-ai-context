# Vault 버전 관리

## 현재 기준선

- 이 Vault는 2026-07-27부터 로컬 Git 저장소로 관리한다.
- 기본 브랜치: `main`
- v1 기준선 커밋: `877862c`
- 원격 저장소: 연결하지 않음
- Push·Pull·원격 생성은 사용자의 명시적 승인 전에는 수행하지 않는다.

## 작업 시작 전

1. Vault가 Git 저장소인지 확인한다.
2. 현재 브랜치와 변경 파일을 확인한다.
3. 다른 AI나 사용자의 미커밋 변경이 있으면 먼저 범위를 분리한다.
4. 충돌 가능성이 있는 같은 문서를 동시에 수정하지 않는다.

## 커밋 단위

- 정책, 구조, 템플릿 변경은 검증 후 하나의 논리적 로컬 커밋으로 남긴다.
- Inbox 초안 하나마다 커밋할 필요는 없지만, 승격·보관 작업은 검토 단위로 커밋한다.
- 비밀정보가 없는지 확인한 뒤 커밋한다.
- 자동 생성되는 Obsidian 작업 공간 상태는 추적하지 않는다.

## 복구와 비교

- 변경 전후 비교는 Git diff를 우선한다.
- 잘못된 변경을 발견해도 광범위한 강제 되돌리기를 하지 않는다.
- 다른 작성자의 변경이 섞여 있으면 해당 파일을 임의로 폐기하지 않고 사용자에게 보고한다.
- 일회성 ZIP 백업은 보조 수단이며 Git 이력을 대체하지 않는다.
