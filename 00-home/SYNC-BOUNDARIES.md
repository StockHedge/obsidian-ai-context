# AI 간 동기화 범위와 한계

## 실제로 공유되는 것

- Claude Code, Codex, Cursor가 같은 로컬 파일을 읽으면 디스크상의 최신 내용은 공유할 수 있다.
- Git은 누가 무엇을 바꿨는지 비교하고 복구할 수 있게 한다.
- 프로젝트의 `NOW.md`와 Vault의 검증된 기록은 다음 세션이 읽을 수 있는 공용 인계면이다.

## 자동으로 공유되지 않는 것

- 파일이 바뀌었다고 이미 진행 중인 AI 대화의 모델 컨텍스트가 즉시 갱신되지는 않는다.
- 다른 AI의 대화 전문, 내장 메모리, 비공개 내부 추론은 동기화되지 않는다.
- ChatGPT·Gemini 웹 대화는 별도 연결이나 파일 첨부 없이는 이 로컬 Vault를 직접 읽을 수 없다.
- Git 원격 저장소를 연결해도 모델 메모리가 실시간으로 합쳐지는 것은 아니다.

## 운영 의미

- 로컬 AI는 작업 시작·재개·인계 시 기준 파일을 다시 읽는다.
- 중요한 현재 상태는 대화 기억에 맡기지 않고 프로젝트 `NOW.md`에 기록한다.
- 웹 AI에는 필요한 최소 문서만 첨부하거나 승인된 연결 수단을 사용한다.
- 비공개 원격 저장소나 커넥터는 접근성을 높일 수 있지만 비밀정보 검토와 접근 권한 관리가 먼저다.

이 구조의 목표는 모든 AI의 메모리를 합치는 것이 아니라, 검증 가능한 공용 파일을 통해 수동 릴레이를 최소화하는 것이다.
