# 엠보로스 베타테스터 실무 플레이북

> 목적: 첫 5명의 핸드메이드·리빙 셀러와 함께, 실제 결제 없는 스토어 미리보기·개설 경험을 검증한다.
>
> 운영 원칙: 적합한 셀러와의 대화를 넓은 유입보다 우선한다. 이 문서는 실행 방법이고, 실제 후보·인터뷰·이슈의 기록은 운영 스프레드시트를 기준으로 한다.

## 0. 지금의 상태

### 확인된 사실

- 베타는 **실제 결제·실주문 없이** 스토어 미리보기와 개설 경험을 검증한다.
- 대상은 상품·사진·가격을 갖춘 핸드메이드·리빙 소형 셀러다.
- 운영 규모는 5명, 기간은 4주, 주 1회 30분 1:1이다.
- 완주 보상은 Pro 3개월, 개설 지원, 5만원 상품권이다. 후기·사례 공개와 보상은 분리하며, 사례 공개는 선택 동의다.
- 2026-07-28 기준 운영 스프레드시트의 후보 슬롯 30개는 준비됐으나 실제 브랜드·계정·연락 이력은 아직 입력되지 않았다. 현재 병목은 `적합 후보 확보`다.
- Figma에는 랜딩·신청·완료·준비표 화면이 있으나 주요 CTA 프로토타입 전환은 아직 연결되지 않았다.

### 결정

- P1은 인스타그램·스마트스토어에서 이미 판매하는 핸드메이드·리빙 셀러 20명이다.
- P2는 팝업·공방 중심 브랜드 10명이다.
- 첫 4주에는 유료 광고를 집행하지 않는다.

### 가설

- 셀러는 `AI` 자체보다 **상품 3개와 사진으로 내 브랜드 스토어 초안을 만들고, 개설을 함께 받는 경험**에 반응할 가능성이 높다.

### 검증 필요

- 공개 신청 링크가 실제 환경에서 열리고, 신청이 운영자 검토 대기열에 정확히 저장되는지 확인한다.
- 모바일 신청 폼이 선발에 필요한 판매 채널·상품 수·링크·사례 공개 선택 항목을 모두 받는지 확인한다.
- 상품고시·원산지·과세·주문·환불·결제는 이 베타 범위 밖이며, 실판매 전 별도 출시 게이트로 검증한다.

## 2. 모집 전 30분 체크리스트

아래 다섯 가지가 모두 확인된 뒤에만 외부 연락을 시작한다.

- [ ] 신청 링크와 완료 화면이 실제로 열린다.
- [ ] 신청 정보가 운영자 검토 화면 또는 운영 시트에 기록된다.
- [ ] `실제 결제 없는 미리보기 베타`라는 문구가 첫 화면·DM·신청 화면에 동일하게 있다.
- [ ] 4주·주 1회 30분·완주 보상·사례 공개 선택 조건이 동일하다.
- [ ] 응답자에게 줄 수 있는 첫 가게 준비표와 15분 인터뷰 가능 시간이 준비됐다.

이 체크리스트가 미완료면 모집을 넓히지 않는다. 후보 조사만 하고, 외부 발송은 보류한다.

### 후보 적합성 빠른 판정

다음 네 가지를 모두 확인하면 후보로 기록한다.

1. 핸드메이드·리빙 상품을 판매하거나 팝업·공방 경험이 있다.
2. 상품 3개 이상, 사진과 가격을 보유했다.
3. 독립몰 또는 브랜드 페이지가 필요하지만 아직 개설을 미뤘다.
4. 4주 동안 주 1회 30분과 간단한 과업에 참여할 수 있다.

다음은 이번 베타에서 제외한다: 복잡한 옵션 조합, 신선식품·예약형 상품, 실제 결제가 반드시 필요한 셀러, 이미 자사몰을 충분히 운영하는 브랜드.

### 발송 원칙

- 한 메시지에는 반드시 실제 상품 또는 브랜드 관찰 한 줄을 넣는다.
- 하루 5명씩만 보내고, 보내기 전 `01_후보_모집`에 후보·관찰·링크를 먼저 남긴다.
- 운영진 허가 없이 커뮤니티·오픈채팅에 게시하지 않는다.
- 후속 연락은 1회까지만 한다. 미응답을 부정적 반응으로 해석하지 않는다.
- 실제 결제, 판매 성과, 선발, 후기 공개를 보장하지 않는다.

## 5. 모집 퍼널 운영

### 매일 20분 루틴

1. 후보 5명을 조사하고 `01_후보_모집`에 기록한다.
2. 적합한 후보에게만 맞춤 DM을 보낸다.
3. 응답·신청·인터뷰 일시를 당일 기록한다.
4. 폼 제출과 운영자 검토 대기열을 확인한다.
5. 반복되는 질문을 `04_피드백_이슈`에 남긴다.

### 주간 판단

| 흐름 | 목표 | 부족할 때 먼저 볼 것 |
|---|---:|---|
| 후보 | 30명 | 타깃 조건과 검색 키워드 |
| 유효 신청 | 10명 | DM 첫 문장, 보상·조건의 이해도, 신청 폼 마찰 |
| 인터뷰 | 8명 | 일정 제안 방식, 인터뷰 안내 문구 |
| 선발 | 5명 + 대기 2명 | 준비도·참여 가능성·공유 가능성 |

초기 표본이 작으므로 한 채널의 승패를 단정하지 않는다. `유입 → CTA 클릭 → 폼 시작 → 폼 제출 → 적합 판정 → 인터뷰 예약 → 스토어 초안`을 정성 인터뷰와 함께 본다.

## 6. 15분 선발 인터뷰

### 목적·판정

- **타깃:** 신청한 핸드메이드·리빙 셀러
- **문제:** 신청서만으로는 준비도와 4주 참여 의지를 알기 어렵다.
- **원하는 행동:** 셀러가 이번 주 준비 가능 범위와 지속 사용 조건을 구체적으로 말한다.
- **성공 지표:** 8명 인터뷰 완료, 5명 선발·2명 대기, 선발 근거 기록.

### 질문 순서

1. 지금 어떤 상품을 어디에서 판매하고 있나요?
2. 독립몰을 만들거나 미뤘던 이유는 무엇인가요?
3. 상품 3개와 사진·가격을 이번 주 안에 준비할 수 있나요?
4. 지인 3명에게 미리보기 링크를 공유하고 반응을 받을 수 있나요?
5. 실제 판매를 시작하기 전에 반드시 필요하다고 느끼는 것은 무엇인가요?
6. 4주 동안 매주 30분 통화가 가능한 시간대는 언제인가요?

### 점수 기준

| 항목 | 점수 | 근거 |
|---|---:|---|
| 상품 준비도 | 0–3 | 상품 3개·사진·가격을 바로 준비할 수 있는가 |
| 타깃 적합성 | 0–3 | 핸드메이드·리빙이며 독립몰 미리보기의 필요가 분명한가 |
| 참여 가능성 | 0–3 | 4주·주 30분·과업을 수행할 수 있는가 |
| 공유 가능성 | 0–1 | 지인 3명에게 미리보기를 공유할 수 있는가 |

7점 이상을 우선 검토하되, 점수보다 실제 대화의 구체성을 함께 기록한다. 확정 전에는 실결제 미지원, 보상 조건, 개인정보 사용 범위, 사례 공개 선택권을 다시 안내한다.

| W0 | 준비표 제출 | 판매 채널·목표·상품 준비 상태 확인 | 선발 근거, 기대 결과 | 5명 적합 조건 확인 |

| W2 | 상품 3개 등록, 무드·디자인 수정, PC/모바일 확인 | 화면 공유로 등록 흐름과 통제감 확인 | 등록 마찰, 디자인 통제감, 모바일 문제 | 4/5가 상품 3개·모바일 미리보기 완성 |
| W3 | 지인 3명에게 미리보기 링크 공유 | 반응을 이해·신뢰·구매 의도로 분류 | 고객이 이해 못한 내용, 신뢰 저해 요소 | 3/5가 외부 피드백 수집 |
| W4 | 최종 회고 | 계속 사용할 조건과 결제 전 필수 요소 확인 | 추천·비추천 이유, 출시 차단 요소 | 5명 최종 인터뷰, 반복 이슈 상위 5개 |

### 매주 공통 기록 양식

```markdown
## [셀러/브랜드] · [주차]

- 과업 완료: 예 / 아니오
- 걸린 시간:
- 처음 멈춘 지점:
- 셀러가 사용한 표현:
- 관찰한 행동:
- 심각도: 출시 차단 / 개선 우선 / 향후 요청
- 다음 주 약속:
```

## 8. 이슈를 제품 결정으로 바꾸는 법

| 기록 항목 | 작성 기준 |
|---|---|
| 사실 | 화면에서 관찰한 행동 또는 셀러의 짧은 표현만 쓴다. |
| 해석 | 사실과 분리해 가설로 쓴다. |
| 심각도 | `출시 차단` / `개선 우선` / `향후 요청` 중 하나다. |
| 제품 시사점 | 가장 작은 수정 또는 다음 질문을 쓴다. |
| 측정 | 다음 셀러가 해당 지점을 통과했는지 확인할 행동 지표를 쓴다. |

반복되고 영향이 큰 문제를 단발성 기능 요청보다 우선한다. 종료 후 48시간 안에 모든 이슈를 이 기준으로 분류하고, 각 셀러에게 본인 피드백 요약을 전달한다.
