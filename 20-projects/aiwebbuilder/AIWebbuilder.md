## 광고를 내기 전에

반드시 [[표기-주의사항]] 을 먼저 본다. 이 제품은 **광고 문구와 실제 코드가 갈라진 전례**가
반복됐다(티어 표기, 만료 개념, 기한 하드코딩). 금전 혜택을 다루므로 분쟁 소지가 실질적이고,
"코드가 실제로 무엇을 하는가"를 확인하지 않은 문구는 내지 않는다.

## 자주 쓰는 운영 명령

콘솔에 UI 가 없는 것(캠페인 코드 등)은 `admin_cli` 로 한다. `fly ssh` 는 상시 실행
머신에 붙는 것이라 **추가 요금이 없다**.

```bash
fly ssh console -a aiwebbuilder-api \
  -C "sh -c 'cd /app && PYTHONPATH=/app python scripts/admin_cli.py promo'"
```

`promo` 는 CLI 가 낫고(즉시 반영), **정책 변경은 콘솔이 낫다**(CLI 는 재시작 필요).
상세는 [[프로모션-플래그-지도]] 의 "운영 명령" 절.
