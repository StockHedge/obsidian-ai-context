
## 혜택

| 항목 | 값 | 실제 저장 위치 |
|---|---|---|
| 크레딧 |  | `User.preview_credits` |

- 한도 · 1인 1회 여부

## 운영 명령

```bash
GET   /api/promo/admin/list
PATCH /api/promo/admin/CODE?is_active=false
PATCH /api/promo/admin/CODE?expires_at=YYYY-MM-DDT23:59:59%2B09:00
```

⚠️ 만료는 naive UTC 저장. KST 로 끊으려면 `+09:00` 오프셋 필수.
